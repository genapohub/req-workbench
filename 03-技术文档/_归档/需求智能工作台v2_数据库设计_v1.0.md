# 需求智能工作台 v2 数据库设计（v1.0）

## 1. 数据存储方式

本地 SQLite，业务对象以 JSON body 存储，适合一期快速试点和本地开发。

## 2. users

| 字段 | 说明 |
|---|---|
| id | 用户 ID |
| username | 登录账号 |
| name | 显示名称 |
| role_ids | 角色 ID 列表 |
| status | active / disabled |
| password | 加密后的密码 |

## 3. roles

| 字段 | 说明 |
|---|---|
| id | 角色 ID |
| name | 角色名称 |
| permissions | 权限位列表 |

权限位：overview.view、projects.view、projects.manage、requirements.view、requirements.create、requirements.analyze、requirements.review、requirements.export。

## 4. projects

| 字段 | 说明 |
|---|---|
| id | 项目 ID |
| name | 项目名称 |
| company_business | 公司业务 |
| project_background | 项目背景 |
| progress | 项目进度 |
| business_goals | 业务目标 |
| north_star_metric | 北极星指标 |
| business_process | 关键流程 |
| target_users | 目标用户 |
| constraints | 限制条件 |
| created_at / updated_at | 时间戳 |

## 5. requirements

| 字段 | 说明 |
|---|---|
| id | 需求 ID |
| project_id | 所属项目 |
| proposer_id | 提出人 |
| title | 标题 |
| original | 用户原话 |
| scenario | 发生场景 |
| problem | 还原问题 |
| impact | 影响说明 |
| authenticity | 问题真实性 |
| business_relevance | 业务相关性 |
| priority | 投入优先级 |
| depth | 挖掘深度 |
| scope_score / intensity_score / value_score / cost_score | 四维评分 |
| clarifications | 追问记录 |
| evidence | 证据与反证 |
| solutions | 候选方案 |
| analysis_history | 分析历史 |
| deep_dive_suggestions | 深挖建议 |
| status | 评审状态 |
| created_at / updated_at | 时间戳 |

## 6. sessions

| 字段 | 说明 |
|---|---|
| id | session ID |
| user_id | 用户 ID |
| expires | 过期时间 |
