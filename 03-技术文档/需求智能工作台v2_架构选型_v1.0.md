# 需求智能工作台 v2 架构选型（v1.0）

## 1. 结论

最终版采用单体轻量架构，服务于基座信息、需求挖掘和需求辨伪。

| 层 | 选型 |
|---|---|
| Web 前端 | Vue 3 + Vite + Element Plus |
| 后端 API | FastAPI |
| 本地数据库 | SQLite，JSON body 存储业务对象 |
| 登录会话 | HttpOnly Cookie session |
| 本地运行 | PyCharm 分别启动后端和前端 |

## 3. 后端模块

| 模块 | 作用 |
|---|---|
| auth | 登录、退出、当前用户、菜单权限 |
| overview | 工作概览和基座完整度统计 |
| projects | 公司业务、项目背景、项目进度维护 |
| requirements | 需求提交、追问、证据、分析、评审、导出 |

## 4. 前端主题与样式架构

- **单一事实源**：`frontend/src/styles/tokens.css`（Design Tokens v3.0）。所有颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效取自 Token，组件内禁止硬编码。
- **换肤机制**：只改 Token 取值、不改变量名 → 组件与页面零改动即可整体换肤（2026-10-01 由飞书浅色切到 Spotify 式深色即按此方式完成）。浅色值保留在 `[data-theme="light"]` 骨架。
- **EP 覆盖层**：`overrides.css` 统一处理 teleport 到 body 的组件（dialog / drawer / message / dropdown）与按钮几何。
- **组件化**：11 个公共组件（AppSidebar / AppTopbar / PageHeader / PanelCard / DataTable / FormDialog / StatCard / EmptyState / SectionTitle / MethodCheckCard / StatusTag），页面内不留私有 toolbar / page-head 样式。
- **表格能力**：`DataTable` 支持密度切换；筛选与列显隐由页面自持状态（列 `v-if` + `:key` 强制重建）。

## 5. 设计取舍

- 不引入多智能体框架，避免一期复杂度过高。
- 不引入独立向量库，先用结构化字段和证据记录支撑评审。
- 不做复杂后台配置，角色和权限以内置演示数据支撑试点。
- AI 分析只做辅助判断，最终结论由人确认。
- 前端不引入组件测试框架（Vitest）与状态库（Pinia）：一期以「后端 pytest + vite build + Playwright 冒烟」兜底，会话状态用 `store/session.js` 的 reactive 单例即可。
