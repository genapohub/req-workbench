# 内部客户管理系统（CRM + 项目管理）需求清单 V2.0

> 版本说明：V1.0 初版 → V2.0 整合实施计划表（双责任人、计划/承诺双时间、上线前必完清单），并补充 M3 项目管理原型页面清单。
> 已确认事项：实施计划模板全客户通用；项目信息通过微信群触达（周报一键复制转发）；UAT 反馈与投诉合并为统一工单中心；任务区分"内部计划完成时间"与"客户承诺时间"。

---

## 一、系统定位与使用角色

| 角色 | 说明 |
|---|---|
| 客户（甲方，含代理商） | 提需求、看项目进度、接收待办事项（提供资料等）、UAT 反馈、续费、活动报名、转介绍 |
| 客服/客户成功 | 客户跟进、到期提醒、投诉受理、甲方协作任务催收 |
| 销售 | 报价、合同、续费跟进 |
| 项目经理（乙方内部） | 制定实施计划、分派任务、把控节点、维护进度 |
| 开发/实施人员 | 处理需求、更新任务状态 |
| 管理层 | 项目看板、风险预警、统计报表 |

---

## 二、功能模块需求

### M1 客户管理

1. 客户档案：基本信息（名称、行业、联系人、电话、来源渠道、所属销售）、多联系人管理
2. 客户标签/分级（普通/VIP/战略客户）
3. 客户状态流转：潜在 → 已签约 → 服务中 → 到期预警 → 已流失/续费
4. 跟进记录：拜访打卡、每次沟通记录、下次跟进时间、跟进提醒（防止客户被遗忘）
5. 客户遗漏预警：N 天未跟进自动标红并提醒销售/客服负责人
6. 客户查重（按名称/电话）
7. 客户合并、转移归属人（销售离职交接）

### M2 合同管理

1. 合同录入/上传扫描件，关联客户，合同编号自动生成
2. 合同关键字段：金额、签订日期、服务期限（开始/结束日期）、付款方式、产品模块清单
3. 合同状态：待生效/生效中/即将到期/已到期/已终止
4. 收款计划与到账登记（支持分期）、应收台账
5. 合同到期自动联动 M6 提醒
6. 合同续签、变更记录（版本留痕）

### M3 项目管理与实施交付（核心模块）

#### 3.1 实施计划模板（WBS 工作分解）

1. 预置标准实施阶段模板，全客户通用：
   - **阶段一：资料整理**
     - 商城准备工作（公众号、商城小程序、CRM 小程序、微信支付申请）
     - 基础资料整理（客户资料上传、商品资料、客户一户一价、商品图片、组织架构体系、打印模板确定）
     - 商城资料（装修模板、轮播图、菜单栏、展示数量、条码模块、活动模块、产品详情图、商品尺寸）
     - 开发需求
   - **阶段二：测试运行**
     - 上线功能确定（业务员管理、司机配送、库存预警、打印方式）
     - 培训测试
     - UAT 测试（商城模块、CRM 模块、后台）
   - **阶段三：试运行与上线**
     - 期初录入
     - 试运行
     - 正式上线 + 验收
2. 模板可配置：阶段、任务类别、任务项、标准工期（如"商城准备 20-40 天、基础资料 14 天"）可维护，新项目一键套用模板生成计划

#### 3.2 任务管理（核心字段对齐实施计划 Excel 表）

| 系统字段 | 对应 Excel 列 | 说明 |
|---|---|---|
| 所属阶段 | 阶段 | 资料整理/测试运行/试运行 |
| 任务类别 | 类别 | 如"商城准备工作" |
| 任务内容 | 计划完成工作 | 支持子任务逐项打勾 |
| 乙方责任人 | 乙方责任人 | 内部员工 |
| 甲方责任人 | 甲方责任人 | 关联客户联系人 |
| 内部计划完成时间 | 计划完成时间 | 乙方自己的排期 |
| 客户承诺时间 | —（新增） | 与内部计划分开，单独维护 |
| 前置事项 | 备注（上线前需完成） | 标记"是否上线前必须完成" |
| 责任方 | — | 乙方做 / 甲方配合 / 需甲方提供资料 |
| 状态 | — | 未开始 / 进行中 / 已完成 / 已逾期 / 已取消 |

- 任务依赖：前置任务完成后才能开始（如"微信支付申请完成"→"商城能收款"）
- 任务可批量导入（粘贴 Excel 生成）

#### 3.3 "上线前必须完成"事项清单（关键把控点）

1. 每个任务可标记【上线前必须完成】（对应备注列红底事项）
2. 上线检查清单（Go-Live Checklist）：系统自动汇总所有"上线前必须完成"事项，逐项确认打勾，全部完成才能发起上线流程，缺一不允许上线
3. 检查清单支持甲方、乙方双确认

#### 3.4 甲方协作任务与催收（防延期、防客诉）

1. 标记为"需甲方提供/确认"的任务，自动推送待办给客户（企业微信群/短信通知）
2. 甲方超期未处理：自动升级提醒（第 1 天提醒客户对接人 → 3 天提醒客户负责人 → 5 天同步给乙方管理层），并标记"因甲方原因延期"
3. 延期原因留痕，责任可追溯，避免项目扯皮

#### 3.5 项目看板与进度把控

1. 项目总览看板：每个项目一张卡片，显示当前阶段、整体进度%、逾期任务数、距客户承诺上线日天数
2. 甘特图视图 + 看板视图 + 任务列表视图
3. 预警规则：
   - 任务逾期 → 红色标记，通知乙方责任人+项目经理
   - 阶段逾期 → 通知管理层
   - 项目整体延期风险 → 项目标红
4. 每个项目展示：项目经理、开发量（人天）、Bug 数、当前阶段
5. 客户可见进度视图：客户登录后按阶段看到整体进度（不暴露内部任务细节与内部计划时间），减少催问和客诉

#### 3.6 UAT 测试与验收管理（与工单中心合并）

1. UAT 任务管理：按模块（商城/CRM/后台）建立测试任务，记录计划时间
2. 客户反馈入口：UAT 期间客户提交问题/调整意见，反馈自动进入统一工单中心
3. UAT 结论记录：通过/不通过、遗留问题清单
4. 培训记录：培训时间、参加人、培训资料上传
5. 试运行管理：试运行起止时间（如 7 天）、试运行问题记录、试运行通过确认
6. 验收流程：验收单在线确认或上传签字扫描件，项目转"已交付"

#### 3.7 项目文档与协作

1. 项目资料库：按项目归档甲方提供的资料（商品图、模板、资质文件等）
2. 项目内留言/讨论区，沟通记录留痕
3. 自动生成项目周报：本周完成、下周计划、逾期事项、需甲方配合事项，支持一键复制为微信排版格式发微信群

### M4 需求管理（客户提需求 → 全生命周期）

1. 客户提交需求入口（文字+截图附件），自动关联客户账号
2. 需求池列表，状态流转：已提交 → 已受理 → 评估中 → 已报价（待确认）→ 已排期 → 开发中 → 待验收 → 已上线 → 已关闭
3. 需求评估：评估人、开发量（人天/时长）、价值评估、优先级
4. 需求与客户确认机制：报价后客户在线确认/驳回，留痕
5. 需求处理超时提醒（超 N 天未响应提醒负责人，防客诉）
6. 需求上线后客户评价/评分（星级+文字）
7. 与 M3 打通：项目内产生的开发需求、UAT 反馈统一进入需求池/工单中心

### M5 需求报价 / 收费标准

1. 报价单创建：关联需求/项目，明细行（产品模块、功能点、人天、单价、折扣）
2. 收费标准库：人天单价、各模块标准价目，报价时可引用，销售可查看
3. 报价单状态：草稿 → 已发送 → 客户已确认/已拒绝 → 已转合同/订单
4. 报价单在线发送客户确认（电子确认或导出 PDF）
5. 报价历史与版本记录

### M6 到期提醒与在线续费

1. 到期预警规则：到期前 90/60/30/7 天分级提醒（系统消息+企业微信群/短信）
2. 提醒到人：所属客服、销售、管理层
3. 客户侧：续费入口，展示到期时间、续费方案、在线支付
4. 续费订单与收款确认，续费后合同自动延期
5. 已到期未续客户进入流失挽回跟进列表

### M7 账户、充值与积分体系

1. 客户账户余额：支持预充值（可支付需求开发费、服务费）
2. 充值记录、消费流水（每笔扣费关联需求/合同/订单）
3. 积分体系：
   - 转介绍送积分，消费返积分，活动/培训奖励积分
   - 积分规则后台可配（获取比例、有效期、兑换比例）
4. 积分兑换：兑换服务（抵扣开发费/服务费/续费）或兑换实物（兑换记录+发货管理）
5. 余额/积分变动通知客户

### M8 转介绍

1. 客户生成专属推荐链接/邀请码，分享给同行
2. 被推荐人注册/签约后，推荐人自动获得积分奖励（按签约金额比例，后台可配）
3. 转介绍关系链记录、奖励明细、积分入账记录
4. 转介绍排行榜（可选，激励作用）

### M9 活动/会议报名

1. 活动创建：标题、时间、地点/线上链接、名额、报名截止日期、是否收费
2. 报名入口（H5/小程序），报名审核（可选）、签到核销
3. 报名表单可配置（姓名、公司、职务、联系电话等）
4. 报名成功通知、活动前提醒
5. 参与记录关联客户档案，参加培训/活动可送积分（联动 M7）

### M10 评价与投诉（并入工单中心）

1. 需求上线后、续费后自动邀请客户评价（评分+标签+文字）
2. 投诉入口：客户提交投诉 → 自动生成投诉工单（红色高亮，默认高优先级）→ 处理流程（受理→处理→回复→关闭）
3. 投诉 SLA：24 小时内响应，超时自动升级到管理层
4. 投诉类工单关闭后强制客户评价
5. 评价/投诉与客户档案、项目关联，纳入客户健康度

### M11 代理商选品报价

1. 代理商等级体系（等级对应不同拿货折扣，后台可配）
2. 产品库：产品/模块清单、标准价、代理价（按等级）、产品说明文档
3. 代理商登录后可自助选产品、生成报价单并转发给自己的客户
4. 代理商报价记录、成交统计、返点/积分核算
5. 防止越级：代理价对代理商可见，终端客户不可见

### M12 统计报表（管理层驾驶舱）

1. 客户：新增/流失/到期/续费率、客户遗漏（超时未跟进）清单
2. 项目：在研项目数、按期交付率、平均交付周期、逾期项目数、甲方原因延期占比、各阶段平均耗时
3. 需求：开发量（人天）统计、需求处理时长、满意度评分
4. Bug/工单：新增/解决/遗留、按项目分布
5. 收入：合同额、到账、续费收入、需求开发收入
6. 转介绍、积分发放/消耗、活动参与统计

### M13 系统管理

1. 组织架构、账号、角色权限（按模块+数据范围）
2. 审批流（报价折扣审批、合同审批、充值/积分调整审批、上线审批）
3. 消息中心：站内信、短信、企业微信群机器人通知（到期、逾期、待办、投诉预警）；项目周报一键复制微信格式发群
4. 操作日志、参数配置（预警天数、积分规则、价目、SLA）
