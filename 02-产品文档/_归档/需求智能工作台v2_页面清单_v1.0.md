# 需求智能工作台 v2 页面清单（v1.0）

| # | 页面 | 路由 | 核心用途 |
|---|---|---|---|
| 1 | 登录 | `/login` | 账号登录 |
| 2 | 工作概览 | `/overview` | 查看基座完整度和需求判断分布 |
| 3 | 基座信息 | `/projects` | 新建和编辑公司业务、项目背景、项目进度 |
| 4 | 需求挖掘 | `/requirements` | 提交原话、查看列表、进入详情 |
| 5 | 需求详情抽屉 | `/requirements?req={id}` | 追问、证据、分析、辨伪、导出 |

## 导航结构

```text
工作概览
基座信息
需求挖掘
```

## 页面关系

```text
登录 → 工作概览
工作概览 → 基座信息 / 需求挖掘
基座信息 → 编辑项目基座
需求挖掘 → 需求详情抽屉
需求详情抽屉 → 智能分析 / 深挖建议 / 导出需求卡
```
