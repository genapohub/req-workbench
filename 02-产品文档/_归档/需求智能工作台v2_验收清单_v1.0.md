# 需求智能工作台 v2 验收清单（v1.0）

## 1. 功能验收

| 编号 | 场景 | 验收标准 |
|---|---|---|
| AC-01 | 登录后查看菜单 | 只显示工作概览、基座信息、需求挖掘 |
| AC-02 | 新建项目基座 | 支持公司业务、项目背景、项目进度字段 |
| AC-03 | 基座缺失 | 可保存项目，但需求提交和智能分析返回明确提示 |
| AC-04 | 提交用户原话 | 完整基座项目下可提交需求，状态为草稿 |
| AC-05 | 缺证据分析 | 保持问题真实性为待验证，不生成已佐证结论 |
| AC-06 | 支持证据分析 | 有支持证据、真实场景和问题描述时可判为已佐证 |
| AC-07 | 反证分析 | 只有反证时标记存在反证，优先级建议为低 |
| AC-08 | 低频高影响 | 不因频率低自动不采纳 |
| AC-09 | 深挖建议 | 能提示缺场景、缺影响、缺证据、缺评分等问题 |
| AC-10 | 导出需求卡 | Markdown 中包含基座信息、原话、真实问题、证据和评审记录 |
| AC-11 | 权限隔离 | 普通员工只能看到自己的需求，PM 可评审授权需求 |
| AC-12 | 旧范围清理 | 页面和接口不暴露最终范围外入口 |
