# 项目背景（v1.0）

## 1. 项目定位

需求智能工作台 v2 是企业内部 PM 使用的需求挖掘和辨伪工具。它不替人拍板，而是帮助团队在评审前说清楚：用户原话背后的真实问题是什么，证据是否充分，是否贴合当前业务和项目阶段。

## 2. 当前目标

| 目标 | 说明 |
|---|---|
| 提升需求判断质量 | 避免把用户给出的方案直接当需求 |
| 强制业务基座 | 使用前先补公司业务、项目背景、项目进度 |
| 保留证据链 | 区分用户陈述、证据、反证和 AI 推断 |
| 支撑人工评审 | 输出可评审的需求卡草案 |

## 3. 一期范围

- 登录与菜单权限
- 工作概览
- 基座信息维护
- 需求提交
- 追问与证据
- 智能分析与深挖建议
- 人工评审状态
- Markdown 需求卡导出

## 4. 成功标准

团队能更快说清楚一条需求的真实场景、证据、业务相关性和取舍理由。
